# MIKA_autoRecorder - MIKATYPE自動記録
MIKATYPEのタイピング記録を自動的に取得してクリップボードに保存する拡張機能です  
取得する値は、打鍵数・入力速度・ミスタッチ数の3つです  

## 機能
### 1回分の打鍵数・入力速度・ミスタッチ数を、1行のタブ区切りでクリップボードに保存します
例えば、  
1回目の打鍵数:377、入力速度:228.0、ミスタッチ数:24  
2回目の打鍵数:386、入力速度:236.0、ミスタッチ数:24  
このときクリップボードに保存される文字列は以下の通りです  
```tsv
377	228.0	24
386	236.0	24
```

### 打鍵数が0または入力速度が0の時は保存しません
1文字目で間違えた等でキャンセルしたときはクリップボードに保存しません
